# NOXCAT TCG

NOXCAT 黑貓的集換式卡牌遊戲：開卡包、收集圖鑑、組牌對戰、在市場買賣卡片。

- 97 張卡：三彈卡包（NOXCAT 集結、異色重生、覺醒之戰）加 8 張基本資源
- 3D 開卡包，一次開一包或五包，每包 $5（遊戲內的假額度）
- 對戰：用自己抽到的卡組 40 張牌組，跟電腦打，或開房間跟朋友連線對戰
- 卡片市場：上架、購買、回收（每張 $0.60）、價格走勢、AI 收購商

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 卡包網站：故事、開卡包、圖鑑、規則 |
| `battle.html` | 對戰桌面與組牌 |
| `tcg-core.js` | 卡片資料和卡面繪製 |
| `engine.js` | 對戰規則引擎和電腦 AI |
| `ui.js` | 對戰畫面、特效、連線對戰 |
| `market.js` | 錢包和卡片市場 |
| `art/` | 97 張卡圖 |

## 在自己電腦上跑

需要用本機伺服器打開（直接雙擊檔案的話，卡圖會載不出來）：

```bash
python3 -m http.server 8000
```

然後打開 http://localhost:8000

## 放到 GitHub Pages

Settings → Pages → Source 選 `main` 分支、根目錄 `/`，存檔後等一兩分鐘就會有網址。

## 只能在 claude.ai 上用的功能

**連線對戰**和**卡片市場的交易**用到 claude.ai 提供的即時連線和共用資料庫。在 GitHub Pages 或自己電腦上打開時：

- 開卡包、圖鑑、規則、跟電腦對戰都正常
- 錢包是 $10,000 的本機額度，存在這個瀏覽器裡
- 市場可以瀏覽和回收卡片，但不能跟其他人買賣
- 連線對戰不能用

要讓這兩個功能在 GitHub Pages 上也能用，需要另外接一個後端（例如 Firebase 或 Supabase）。
